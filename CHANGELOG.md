# Changelog

## 0.1.0 - 2026-08-23

- Implemented hoisted tour state with lifecycle callbacks and duplicate-step validation.
- Added adaptive tooltip positioning with fallback placements and RTL/LTR support.
- Added Compose target lifecycle tracking, full-screen overlay and RoundedRectangle/Circle
  spotlight rendering.
- Added configurable tooltip actions, progress labels, overlay styling and Compose animations.
- Added Material 3 tooltip customization and a multi-step sample screen.
- Added JVM state/positioning/target tests and a Compose instrumentation test source.
- Added accessibility semantics for overlay dismissal, tooltip content and navigation controls.
- Added Maven publication with release AAR and sources JAR support, optional in-memory signing,
  local publication verification and GitHub Actions workflows.
- Added contributor, security, conduct and release documentation.
