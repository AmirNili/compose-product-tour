# Changelog

## [0.1.0] - 2026-08-23

- Added modular core, UI, animation, Material 3, and sample modules.
- Added hoisted tour state with lifecycle callbacks and validation.
- Added lifecycle-aware target registration and adaptive tooltip positioning.
- Added rectangle, rounded rectangle, and circular spotlight rendering.
- Added RTL/LTR support, resource-backed step text, and accessibility semantics.
- Added configurable overlay, tooltip, Material 3, and animation styles.
- Added unit tests, Compose test sources, Maven publishing, and GitHub Actions.
